# Definition of Done commune

Une user story n'est terminée que si, en plus de ses critères d'acceptation et de sa Definition of Done spécifique, elle respecte tous les points suivants :

- code sur une branche dédiée à la user story, avec des commits explicites, puis fusionné dans la branche principale ;
- HTML et CSS valides au validateur du W3C ;
- interface conforme à la charte Razer et responsive (mobile, tablette, desktop) ;
- fonctionnement testé sur 3 navigateurs différents ;
- formulaires validés côté client et côté serveur, avec des messages d'erreur clairs en français ;
- pages et actions réservées inaccessibles aux utilisateurs sans les droits nécessaires.

## Pour l'agent
- Ne jamais déclarer une user story terminée sans avoir passé chaque point en revue.
- Indiquer explicitement ce qui n'a pas pu être vérifié, notamment les tests sur plusieurs navigateurs et la validation W3C, que PIDEILLOU devra faire lui-même.
- Le catalogue doit se charger en moins de 3 secondes (DEC-b).
- Évaluation : la note combine la quantité de user stories réalisées et la qualité (application et réalisation). Un livrable qui fonctionne parfaitement vaut mieux que beaucoup de fonctionnalités bancales.
